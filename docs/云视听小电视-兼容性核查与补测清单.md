2026-11-01 核查官方 TV 下载包，实际版本为 **1.8.9**，原生库只有 `armeabi-v7a`。Google 官方说明，Apple Silicon 的 Google TV 模拟器镜像使用 64 位用户空间。该 APK 与这种镜像存在 ABI（Application Binary Interface，应用二进制接口）不兼容，已满足本轮停止条件。

六条用户路径均为“阻塞”。本报告不使用第三方旧截图评价 1.8.9，也不推断 Tizen 的播放性能、HDR 或 Atmos 兼容性。

## 兼容设备准备与停止条件

使用用户已有、明确支持该 APK 的 Android TV / Google TV 实体设备，通过 HDMI 连接电视。本轮不购买设备，不研究其他模拟器，不改网络或代理配置。若暂无设备，保留待办，不将辅助资料研究称为运行测试。

在有兼容设备后，先由测试人员填写目标序列号和 APK 绝对路径。所有 ADB 命令指定同一个设备，避免影响其他设备：

```bash
TV_SERIAL='<目标设备序列号>'
TV_APK='<官方 APK 的绝对路径>'
adb -s "$TV_SERIAL" shell getprop ro.product.cpu.abilist
adb -s "$TV_SERIAL" shell getprop ro.build.version.release
adb -s "$TV_SERIAL" shell getprop ro.product.model
adb -s "$TV_SERIAL" shell wm size
unzip -Z1 "$TV_APK" | awk -F/ '/^lib\/[^/]+\/.*\.so$/ {print $2}' | sort -u
shasum -a 256 "$TV_APK"
```

确认设备 ABI 包含 `armeabi-v7a`，再核实 APK 的版本和 TV 启动入口。若已有不同签名的同包应用，不卸载、不清除其数据；保留安装冲突，另行处理。新设备安装使用：

```bash
adb -s "$TV_SERIAL" install "$TV_APK"
```

安装或进入首页失败时，保存原始错误和当时截图后停止，不替换成手机 APK，不绕过设备识别或 DRM。进入首页后优先用实体遥控器；ADB 的 `19/20/21/22/23/4` 分别可辅助模拟上、下、左、右、确认和返回。混合输入必须分别记录。

需要账号时由用户扫码，不读取桌面浏览器凭证。播放会产生观看历史；不购买、不点赞、不投币、不关注、不收藏、不删除历史。画质和弹幕设置修改前先记录原值，测试后恢复。本轮因 ABI 提前停止，没有产生这些账号或设置变化。

补测优先检查播放控制和焦点/返回恢复，其次检查中文搜索及首页信息密度。这些路径直接影响看视频时的操作次数；具体产品修改须等本轮实测证据。建议清单按用户收益排序，同等收益优先低成本方案；每项标明截图编号、源码依据、受益任务、估计改动范围及未验证之处。

若需要运行 bilibili-tizen 对照，只使用现有 `node tools/devserver.mjs --no-auth`，以未登录状态在 1920×1080 下观察；不运行默认会借用 Chrome 登录态的模式。本轮未启动开发服务器、未运行浏览器对照、未部署电视。浏览器对照只能说明所观察的界面行为，不能充当 Tizen 原生播放验收。
